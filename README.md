 # Finance Analysis Dashboard

## Project Overview
This project is an interactive Power BI dashboard designed
to analyze financial transactions and generate business insights.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Excel/CSV
- Data Visualization

## Key KPIs
- Total Transaction Amount
- Successful Transactions
- Failed Transactions
- Pending Transactions
- Customer Segments
- Gender Analysis
- State-wise Amount
- Transaction Type Analysis
- Monthly Amount Analysis

## Dashboard Features
- Year Filter
- Customer Segment Filter
- Transaction Status Analysis
- State-wise Analysis
- Gender Analysis
- Transaction Type Analysis
- Monthly Trend Analysis
